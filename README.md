# 📄 AI Resume Screener

An AI-powered HR tool that matches candidate resumes with job descriptions.

### Features
- Paste Job Description and Resume
- Calculates Match Score %
- Shows Matched Tech Skills
- Built with Streamlit & Python

### How to Run
pip install -r requirements.txt
streamlit run app.py
